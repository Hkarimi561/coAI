# docker mcp tools call

Call a tool

## Usage

```console
docker mcp tools call
```

## Description

Call a tool

## Options

| Option | Default | Description |
|---|---|---|
| `--format` | `list` | Output format (json\|list) |
| `--gateway-arg` | `[]` | Additional arguments passed to the gateway |
| `--verbose` | `false` | Verbose output |
| `--version` | `2` | Version of the gateway |
