# docker desktop version

Show the Docker Desktop CLI plugin version information

## Usage

```console
docker desktop version [OPTIONS]
```

## Description

Show the Docker Desktop CLI plugin version information

## Options

| Option | Default | Description |
|---|---|---|
| `--format, -f` |  | Format the output. Values: [pretty \| json]. (Default: pretty) |
| `--short` | `false` | Shows only the version number |
