# docker desktop stop

Stop Docker Desktop

## Usage

```console
docker desktop stop [OPTIONS]
```

## Options

| Option | Default | Description |
|---|---|---|
| `--detach, -d` | `False` | Do not synchronously wait for the requested operation to complete |
| `--force` | `False` | Force Docker Desktop to stop |
| `--timeout` | `0` | Terminate the running command after the specified timeout with a non-zero exit code. A value of zero (the default) or -1 means no timeout |
