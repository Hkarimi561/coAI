# docker volume

Manage volumes

## Usage

```console
docker volume COMMAND
```

## Description

Manage volumes. You can use subcommands to create, inspect, list, remove, or
prune volumes.

## Subcommands

- `docker volume create`
- `docker volume inspect`
- `docker volume ls`
- `docker volume prune`
- `docker volume rm`
- `docker volume update`
