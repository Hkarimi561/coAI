# docker swarm

Manage Swarm

## Usage

```console
docker swarm
```

## Description

Manage the swarm.

## Subcommands

- `docker swarm ca`
- `docker swarm init`
- `docker swarm join`
- `docker swarm join-token`
- `docker swarm leave`
- `docker swarm unlock`
- `docker swarm unlock-key`
- `docker swarm update`
