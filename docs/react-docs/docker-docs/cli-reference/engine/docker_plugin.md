# docker plugin

Manage plugins

## Usage

```console
docker plugin
```

## Description

Manage plugins.

## Subcommands

- `docker plugin create`
- `docker plugin disable`
- `docker plugin enable`
- `docker plugin inspect`
- `docker plugin install`
- `docker plugin ls`
- `docker plugin push`
- `docker plugin rm`
- `docker plugin set`
- `docker plugin upgrade`
