# docker offload status

Show the status of the Docker Offload connection

## Usage

```console
docker offload status [OPTIONS]
```

## Options

| Option | Default | Description |
|---|---|---|
| `--format, -f` | `pretty` | Format of output (default: pretty, one of: pretty\|json) |
| `--watch, -w` | `false` | Watch for status updates |
