# docker buildx debug

Start debugger

## Description

Start debugger

## Subcommands

- `docker buildx debug build`

## Options

| Option | Default | Description |
|---|---|---|
| `--invoke` |  | Launch a monitor with executing specified command |
| `--on` | `error` | When to launch the monitor ([always, error]) |
| `--builder` |  | Override the configured builder instance |
| `--debug, -D` | `false` | Enable debug logging |
